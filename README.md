# Complete Business Analysis Project

## 1. Project Overview

This project focuses on analyzing business data using Python to identify useful patterns, understand business performance, and develop data-driven recommendations.

The project covers three business areas:

* House Price Analysis
* Customer Churn Analysis
* Sales Performance Analysis

## 2. Project Objectives

* Analyze business datasets using Python.
* Perform data cleaning and Exploratory Data Analysis (EDA).
* Apply statistical analysis techniques.
* Build a Machine Learning model for customer churn prediction.
* Create meaningful data visualizations.
* Provide business recommendations.

## 3. Datasets

This project uses three separate datasets:

| Dataset        | Records |
| -------------- | ------: |
| House Prices   |     300 |
| Customer Churn |     500 |
| Sales Data     |     100 |
| **Total**      | **900** |

**Note:** These datasets are analyzed separately. The Customer Churn dataset meets the 500-record minimum requirement individually.
